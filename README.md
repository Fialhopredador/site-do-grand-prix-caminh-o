# SIGLV

SIGLV — Sistema Integrado de Gestão e Liberação de Veículos.

Sistema demonstrativo para gestão logística de caminhões em ambiente industrial.

## Funcionalidades

- Dashboard operacional
- Agendamento de caminhões
- Controle de operação
- Gestão de docas
- Alertas de atraso
- Simulação de um dia
- Eventos inesperados
- Cenários "E se?"
- Comparação de cenários
- Indicadores
- Histórico
- Gêmeo Digital demonstrativo
- Configurações operacionais

## Objetivo

O SIGLV busca reduzir filas, atrasos e tempo ocioso na operação logística industrial.

Fluxo principal:

Agendamento → Portaria → Pesagem → Pátio → Doca → Carga/Descarga → Conferência → Saída

## Observação

Os dados exibidos são demonstrativos e não representam dados reais de empresas.

O Gêmeo Digital atual também é demonstrativo. Em uma implantação real, poderia ser substituído por dados CAD, BIM, fotogrametria, 3D Tiles ou levantamento da planta industrial.

## Execução

O projeto funciona diretamente no navegador.

Arquivos principais:

- index.html
- styles.css
- app.js

Não é necessário instalar dependências ou executar build.

## GitHub Pages

Para publicar:

1. Acesse `Settings`
2. Entre em `Pages`
3. Em `Build and deployment`, escolha `Deploy from a branch`
4. Selecione a branch `main`
5. Escolha `/ (root)`
6. Clique em `Save`

Depois de alguns minutos, o GitHub disponibilizará o endereço público do SIGLV.
